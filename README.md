# Student Record Management System

## Project Introduction
The Student Record Management System (SRMS) is a C programming mini project used to store and manage student information efficiently.

## Objective
- To store student records efficiently.
- To add, delete, and search student details.
- To manage student data using linked lists and structures.
- To display student information easily.

## Technologies Used
- C Programming
- Structures
- Linked List
- Pointers

## Modules
1. Student Management Module
2. Add Student Module
3. Delete Student Module
4. Search Student Module
5. Display Student Module

## Project Features
- Add new student records.
- Delete student records using Student ID.
- Search student records using Student ID.
- Display all student records.
- Store student ID, name, department, and marks.

## How to Run
1. Download the C source code.
2. Open it in a C compiler.
3. Compile and run the program.
4. Select an option from the menu.
